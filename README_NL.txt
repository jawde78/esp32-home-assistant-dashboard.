HOME ASSISTANT DASHBOARD – LVGL PRO PROJECT
===========================================

Doelapparaat: Waveshare ESP32-S3-Touch-LCD-7
Resolutie:     800 x 480 (landscape)
LVGL:          9.5.0

INHOUD
------
project.xml          Projectconfiguratie en displayresolutie
globals.xml          Gedeelde kleurconstanten
screens/home.xml     Eerste dashboard-scherm

BEKIJKEN
--------
Dit project is opgeslagen in een PRIVÉ GitHub-repository.
De officiële online LVGL Viewer kan een privéproject mogelijk niet openen
zonder passende GitHub-autorisatie. Maak de repository niet openbaar om dit
te omzeilen; gebruik eventueel de lokale LVGL Pro Editor of een aparte
tijdelijke openbare kopie als je bewust code wilt delen.

LET OP
------
Dit is een eerste visuele LVGL Pro XML-proefversie met fictieve gegevens.
De layout is op 800x480 gericht. De XML is niet met de LVGL Pro CLI gevalideerd
in deze omgeving. Als de Viewer of Editor een XML- of fontfout meldt, pas ik
het project aan op basis van de foutmelding.

Er is nog geen Home Assistant-, MQTT- of hardwarekoppeling. De schermen zijn
bedoeld om eerst de vormgeving en indeling te beoordelen.
