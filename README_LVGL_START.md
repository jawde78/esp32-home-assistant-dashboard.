# LVGL Pro starter – Waveshare 7 inch

This starter is based on the official LVGL Pro empty project template from lvgl/lvgl_pro (LVGL 9.5.0).

Display target: 800 x 480.

Start by opening screens/home.xml in LVGL Pro. This is deliberately a minimal starter screen to verify that the project loads before adding dashboard widgets.

Official template source: https://github.com/lvgl/lvgl_pro/tree/master/templates/empty
